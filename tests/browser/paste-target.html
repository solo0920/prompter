Prompter 剪貼簿驗證

在 Prompter 按下「複製」，再分別貼到下面的純文字與富文字目標。

純文字目標應與儲存的 Markdown 完全相同；純文字文件的複製會貼成 Markdown，富文字目標只會在文件含圖片時收到格式化內容與本機圖片。

回到 Prompter

純文字目標

貼到這個 textarea，檢查 Markdown 是否逐字保留，包括標記、空行、圖片參照與結尾換行。

0 個字元

富文字目標

貼到這個 contenteditable 區域，檢查純文字文件是否保留 Markdown 標記；含圖片的文件應一併出現格式化文字與圖片。

0 個字元

這個頁面只供手動驗證，不會上傳或儲存任何內容。若瀏覽器封鎖自動寫入剪貼簿，Prompter 會改用備援或開啟「手動複製」對話框。
